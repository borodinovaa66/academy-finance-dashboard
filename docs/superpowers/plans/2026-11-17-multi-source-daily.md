# Ежедневная сводка: ВТБ, 1С и дебиторка

Поручение: самостоятельно прочитать свежую выписку ВТБ, войти в 1С и таблицу дебиторки под a.borodinov@praktiki.pro, подключить подтверждённые данные к ежедневной сводке. Исходящих сообщений Анне/бухгалтерии нет. Выписки ВТБ и Райффайзена — через Андрея; доступ в Райффайзен пока отложен. Не выпускать ключи с платёжными правами и не подключать платную банковскую услугу без конкретного утверждения условий.

Источники проверяются независимо: банковский серверный снимок Т-Банка по16.11 (102операции); ВТБxlsx1–16.11 (30операций); экспорт дебиторки17.11 (76листов,6отобраны для узкой проверки); выгрузка банковских документов1С и явный выход после чтения. Не складывать 1С/GetCourse с банковскими фактами повторно.

Решение: прежний банк-сборщик сохраняет свою область из4счетов. Дополнительный приватный JSON хранит агрегаты ВТБ, ограниченной сверки дебиторки и1С. API объединяет банки только на общем подтверждённом периоде; при разной свежести ничего не достраивает нулями. Исходный банк можно выбрать отдельно. Проценты, возвраты, тело депозитов и вывод владельцу различаются. Депозит ВТБ не включается в подтверждённый остаток расчётного счёта; чистое размещение показывается справочно, без обещания доступности.

Дебиторка: только агрегаты явно названной выборки, без персональных строк. Полная дебиторка/просрочка остаются неизвестными. Заметка116000к20ноября — отдельное неподтверждённое ожидание, не утверждённый дневной план. Даты занятий не считаются датами платежей; дефекты итогов исходной таблицы не исправляются без поручения.
