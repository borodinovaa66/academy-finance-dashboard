# Финансовый кабинет и ежедневный отчёт

**Цель:** опубликовать существующий светлый кабинет на действующем finance.academy-management.ru; добавить ежедневный и накопительный отчёт и ежедневное обновление.

**Архитектура:** существующий Node.js + SQLite и роли остаются. Проверенные месячные данные доступны только после входа. Новая вкладка читает действующую базу бухгалтерии и отдельный снимок автоматического банковского контура; эти источники не складываются, не перезаписывают друг друга и всегда имеют раздельный периметр. Локальный Codex по расписанию читает существующий защищённый read-only MCP Т-Банка, сверяет выписки, публикует обезличенные дневные агрегаты по существующему SSH-доступу. Банк не получает новых прав; токен не переносится на сервер.

**Ограничения:** банк автоматом пока только четыре одобренных счёта Т-Банка; ВТБ не подменять нулём. Не изменять первичную 1С и ручные записи бухгалтерии. Не отправлять новые сообщения в Bitrix. Сохранить текущие права. Не выдавать денежный поток за прибыль; нулевые обороты подтверждать полной выпиской; разрывы ручной истории показывать. Публикация прямо разрешена запросом пользователя. Базовый commit 4e4030f совпал с production; отдельная ветка codex/finance-cabinet-daily, чужие изменения voronka-dashboard сохранены.

**Проверки:** точность до копейки; возвраты и депозиты/переводы не задваиваются; клиентская выручка не выводится из всех кредитов банка; нерасшифрованное видно отдельно; повторный запуск идемпотентен; никакого публикационного обхода входа; при сбое сохраняется предыдущая подтверждённая версия, видна дата данных.

**Решения:** расписание по умолчанию ежедневно 11:00 Москвы / 12:00 Дубая за предыдущий полный московский день. Выполнение требует включённого компьютера/доступного Codex — видимый предел этой версии. Непрерывного доступа к ВТБ/полной 1С не подтверждено.
