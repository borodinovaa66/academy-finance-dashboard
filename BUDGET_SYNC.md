# Автоматическая синхронизация бюджета Google → сайт

Работает для бюджета **ноября 2026** в [финансовом кабинете](https://finance.academy-management.ru/cabinet#budget).

## Источники и обновление

- [Общий бюджет](https://docs.google.com/spreadsheets/d/1gdj4Iass8LR8jqwQ_2woOKwV0Z3yB1hGQh2uTm84zAo/edit): активные строки листа «План», «Четыре блока», «Свод», «Разбор ФОТ 16.11», «Проект налогов».
- [Закрытая детализация ФОТ](https://docs.google.com/spreadsheets/d/1lipAo1xEMo1mvieSdX-XiWADV1skrx4MB-9FTinlzJU/edit): «Стоимость ФОТ», «Разбор ФОТ», «Проект налогов».
- `finance-budget-sync.timer` проверяет Google **каждые две минуты**, в том числе после перезапуска сервера. Codex и открытый браузер не нужны. Открытый видимый раздел сайта проверяет опубликованные данные **раз в минуту**. Обычная задержка — до трёх минут плюс время запроса Google.
- Суммы, названия, подблоки, пояснения и распределение для диаграмм строятся из текущих строк. Вручную переносить каждое число в HTML больше не требуется. Неизвестные суммы сохраняются как «не определено».
- В исходном плане активность строки определяется заполненным ID свода в A, как в существующих формулах. Новую строку нужно включить также в формулы итогов Google; сайт проверяет совпадение. Это ID строки свода, не восстановленный код BI.

## Контроль и границы

Каждый запуск дважды читает ограниченные диапазоны двух книг и сравнивает содержимое. Если данные изменились во время чтения, есть ошибка формулы, повтор ID, неизвестный верхний блок или не сходятся контрольные итоги, новая версия не публикуется. Сохраняется последняя проверенная версия и выводится предупреждение. Детали ФОТ, не сходящиеся с авторитетным агрегатом, сворачиваются в агрегат с явным пояснением; разница не маскируется выдуманной статьёй.

Расходы и поступления, а также связанный план для ежедневного отчёта публикуются как одна проверенная версия. Указатель текущей версии заменяется атомарно, хранятся три последние версии. Банк, 1С, платёжный реестр и бухгалтерские запросы синхронизатор не затрагивает.

Структура и период источников закреплены для ноября. Переименование служебных листов, перенос расчётных строк ФОТ или создание следующего месяца требуют обновить конфигурацию и проверки; ошибки структуры не превращаются в нули. Автообновление не утверждает бюджет и не подтверждает спорные начисления, налоги или оплату.

## Доступ и эксплуатация

`finance-budget-sync@academy-ceo-dashboard.iam.gserviceaccount.com` имеет только «Читатель» в двух указанных книгах. IAM-роли проекта ему не выдавались. OAuth scope — `spreadsheets.readonly`. Частный ключ создан на сервере и зашифрован systemd; веб-процесс к нему доступа не имеет. Сертификат истекает 17.11.2027: до этой даты нужна замена ключа. Доступы людей и публичность файлов не расширялись.

Сборщик работает как `financebudget` из `/opt/finance-budget-sync`, состояние — `/var/lib/finance-budget-sync`. Изолированный издатель `finance-budget-publish.service` не имеет сети и Google-ключа. Роли сайта сохранены: персональная детализация — только собственнику; административная роль не получает финансовый доступ.

Диагностика администратора через SSH:

```
sudo systemctl list-timers finance-budget-sync.timer
sudo journalctl -u finance-budget-sync.service -u finance-budget-publish.service -n 30
sudo cat /opt/finance-dashboard/private/budget-sync-status.json
```

В журналах — только коды ошибок, время и хеш; нет зарплат, токенов или ключа. При 401/403 создаётся `access-blocked`, сетевые повторы прекращаются. После восстановления прежнего доступа администратор удаляет только `/var/lib/finance-budget-sync/access-blocked` и запускает `sudo systemctl start finance-budget-sync.service`. Сборщик сам права не меняет.

Для остановки: `sudo systemctl disable --now finance-budget-sync.timer`. Последняя опубликованная версия остаётся доступной с постепенно устаревающим временем проверки. Для отката до ручных файлов остановить таймер, сохранить и убрать только `private/budget-sync/current.json`; базовые `private/budget-explorer.json` и `private/cash-plan.json` сохранены. Не откатывать чужие изменения ежедневного отчёта, БД или банковской синхронизации.

## Проверка внедрения

Автоматические тесты проверяют пересчёт иерархии, изменение суммы/названия/пояснения, неизвестные значения, новые строки, дубли ID, изменение структуры, сверку ФОТ, целостность пары снимков, сохранение прошлой версии при ошибке и разграничение доступа.

Сквозная проверка: временная отметка в `План!R16` появилась в защищённом API и браузерной детализации после штатного запуска таймера. Суммы при проверке не менялись. Исходное пояснение восстановлено и проверено следующим штатным запуском; открытая страница сама убрала отметку, сохранив выбранную строку. Проверены циклы 17.11 в 13:54, 13:56, 13:58 и 14:00 МСК. Все 42 автоматических теста прошли. Локальные доказательства (без ключей и токенов) — `local-state/budget-sync-verification.json` и `local-state/budget-sync-*.json`.
