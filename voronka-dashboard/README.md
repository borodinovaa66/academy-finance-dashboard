# Дашборд вебинарной воронки

Первый драфт отдельного SaaS-модуля для запуска потока онлайн-курса через вебинарную воронку.

## Что показывает дашборд

- Регистрации сейчас, цель, процент выполнения.
- Прогноз регистраций к дате вебинара.
- CR из посетителей сайта в регистрацию.
- Сколько регистраций нужно получать в день, чтобы выполнить план.
- Динамику по дням: визиты, посетители сайта, регистрации, CR.
- Воронку трафика: визиты -> сайт -> регистрации.
- Контент и каналы, которые выпускались в дни сбора аудитории.
- Автоматические предупреждения по рискам темпа и конверсии.

## Роли

- `owner` / руководитель: видит дашборд.
- `viewer` / только дашборд: видит дашборд без прав ввода.
- `project` / проджект: видит дашборд и вносит данные запуска.
- `admin` / админ: управляет пользователями и может вносить данные.

## Локальный запуск

```powershell
cd D:\Codex\BI\voronka-dashboard
$env:PORT="3030"
node server.js
```

Открыть: `http://127.0.0.1:3030`

## Тестовые доступы

- Руководитель: `owner` / `owner-change-me`
- Проджект: `project` / `project-change-me`
- Админ: `admin` / `admin-change-me`

Перед продом пароли нужно заменить через env-переменные или через админку.

## Для поддомена

Планируемый домен: `voronka.academy-management.ru`.

До переноса нужно:

1. Утвердить состав показателей и визуальную логику.
2. Решить целевые значения: регистрационная цель, минимальный CR, допустимый риск недобора.
3. Подготовить systemd-сервис на сервере.
4. Настроить nginx reverse proxy.
5. Добавить DNS A-запись для `voronka` на IP сервера.
